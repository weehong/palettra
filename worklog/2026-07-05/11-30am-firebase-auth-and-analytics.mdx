## Implementation Plan

Summary of the executed plan (full `task_plan.md` removed at cleanup per workflow):

1. **Firebase Auth (client-only)** — `lib/firebase.ts` lazy singleton guarded by `NEXT_PUBLIC_FIREBASE_*` env presence; `AuthProvider` context (`onAuthStateChanged`, popup sign-in with redirect fallback) nested in `app/providers.tsx`; sign-in dialog with Google/Twitter/Facebook; user menu in the generator action bar. 3. **Google Analytics** — `@next/third-parties` `<GoogleAnalytics>` in root layout gated on `NEXT_PUBLIC_GA_MEASUREMENT_ID`; typed `lib/analytics.ts` event catalog (~20 events across auth/save/export/import/preview/typography); Web Vitals reporting component.
4. **Tests** — Vitest units for analytics no-op, palette-collection serialization, auth context transitions, sign-in dialog, save/collection flows; all with `firebase/*` mocked. Build/lint/tests must pass with zero env vars set.
